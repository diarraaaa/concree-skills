# YEAH — poster skill pack

Agents: start at [`../SKILL.md`](../SKILL.md), the agent-usable entry point
that directs everything in this skill. This overview is the human-readable
version of the same index, kept in sync with it.

This folder documents the **filière webinar/Space poster** pattern observed
in real YEAH campaign visuals — one representative source poster is copied
locally into [`source-posters/`](source-posters/) for quick visual
reference.

## This is inspiration, not a recurring-topic recipe

Every webinar/Space this pattern was measured from covered a different
filière or topic (mangue, anacarde, etc.) reusing the same template.
Treat it as **compositional DNA to adapt** — swap the topic, filière, date,
moderator, and panelists for the new brief's real, current details.

## Notable finding: "Instagram post" is not a separate template

Files named `Instagram-post---NNN.png` in the source project are **not** a
distinct poster family — every one inspected is this same recurring YEAH
filière/webinar template, just themed to a different crop/agri-filière
topic and re-exported for Instagram. Do not treat "Instagram post" as a
template name; it routes to the one pattern in this skill.

## How to use this pack

1. Open `yeah-filiere-webinar-space.md` and read it in full.
2. Follow its canvas size and zone layout exactly.
3. Fill the content slots with real event details. Never invent a name,
   date, filière, or metric — ask if a slot's real value isn't provided.
4. Reuse real speaker/partner photography when it already exists in the
   project's `assets/`, `imagery/`, or `logos/` folders; otherwise flag
   that a real photo is needed.
5. Keep hex values labeled "approximate" as a starting point; sample the
   cited source image directly if pixel-exact brand color matching is
   required for print or paid media.
