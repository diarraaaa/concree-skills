# Idea Lab — poster, carousel & dossier skill pack

Agents: start at [`../SKILL.md`](../SKILL.md), the agent-usable entry point
that directs everything in this skill. This overview is the human-readable
version of the same index, kept in sync with it.

This folder documents **layout/style patterns** observed in real Idea Lab
campaign visuals — six representative source images are copied locally
into [`source-posters/`](source-posters/) for quick visual reference.

## This is inspiration, not a recurring-cohort recipe

Every item this pack is based on belonged to one specific cohort
(Cohorte 10, the LOGIDOO cohort, a UCAD/makerspace program) and will not
recur under that name or those partners. Treat each type file as
**compositional DNA to adapt** — match a brief to whichever template's
*format* fits, then swap the cohort number, theme, partner names, startup
names, and photos for the new brief's real, current details.

## How to use this pack

1. Identify the brief's format (poster, carousel, spotlight card, or
   dossier page) and open the matching type file.
2. Follow its canvas size and zone layout exactly — these are load-bearing
   composition choices, not arbitrary style.
3. Fill the content slots listed at the bottom of the type file with real
   details. Never invent a name, date, startup, or metric — ask if a
   slot's real value isn't provided.
4. Reuse real photography when it already exists in the project's
   `assets/`, `imagery/`, or `logos/` folders; otherwise flag that a real
   photo is needed.
5. For the carousel pattern, build one cover slide plus one topic slide per
   sub-theme the brief names — never vary the composition slide-to-slide.
6. For the startup spotlight pattern, build one card per startup/founder
   the brief lists — reuse the exact layout, only swapping
   photo/name/pitch/logo.
7. Keep hex values labeled "approximate" as a starting point; sample the
   cited source image directly if pixel-exact brand color matching is
   required for print or paid media.
