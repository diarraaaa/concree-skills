# Goin' Digital — poster skill pack

Agents: start at [`../SKILL.md`](../SKILL.md), the agent-usable entry point
that directs everything in this skill. This overview is the human-readable
version of the same index, kept in sync with it.

This folder documents **poster layout/style patterns** observed in real
Goin' Digital campaign visuals — two representative source posters are
copied locally into [`source-posters/`](source-posters/) for quick visual
reference.

## This is inspiration, not a recurring-session recipe

Every panel this pack is based on was a one-off session. Treat each type
file as **compositional DNA to adapt** — match a brief to whichever
template's panelist count fits, then swap the session topic, date, venue,
and named people for the new brief's real, current details.

## Important: this is a program sub-brand palette, not the CONCREE site palette

Goin' Digital posters use a dark navy + yellow/lime accent, evidenced
directly in the source assets — not CONCREE's site design-system tokens.
Follow the poster's own palette documented in the type file.

## How to use this pack

1. Identify whether the brief has one featured speaker or a moderator +
   lineup, and open the matching type file.
2. Follow its canvas size and zone layout exactly — these are load-bearing
   composition choices (info box position, photo bleed side, QR placement,
   footer partner strip), not arbitrary style.
3. Fill the content slots listed at the bottom of the type file with real
   event details. Never invent a name, date, or metric — ask if a slot's
   real value isn't provided.
4. Reuse real speaker/partner photography when it already exists in the
   project's `assets/`, `imagery/`, or `logos/` folders; otherwise flag
   that a real photo is needed.
5. Generate a real QR code pointing at the actual registration link; never
   place a decorative/non-functional QR graphic.
6. Keep hex values labeled "approximate" as a starting point; sample the
   cited source image directly if pixel-exact brand color matching is
   required for print or paid media.
